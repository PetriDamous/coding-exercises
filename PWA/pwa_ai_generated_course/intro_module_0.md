## **What You Will Build**

You will build **two full React PWAs**:

### **1. REST PWA**

- React + Vite
- Vite PWA plugin
- React Router
- Express backend
- REST endpoints for items, submission, and push subscription
- Full offline support
- Background sync
- IndexedDB caching
- Push notifications
- Install prompt
- App manifest
- Workbox routing + strategies
- Production build + deployment checklist

### **2. Apollo GraphQL PWA**

- React + Vite
- Vite PWA plugin
- Apollo Client
- Apollo Server backend
- GraphQL queries + mutations
- Same PWA features as REST version
- Same UI, same pages, same workflows
- Only the data layer changes

You will end up with **two complete production‑ready PWAs** that behave identically but use different backend technologies.

## **Course Structure**

The course is broken into **8 modules**, each building on the last:

### **Module 1 — Starter Apps**

Build both frontends and both servers.  
No PWA code yet.  
Just the baseline React apps + API layer.

### **Module 2 — Service Worker Fundamentals**

Learn SW lifecycle, caching, Workbox basics, offline fallbacks.

### **Module 3 — Registering the Service Worker**

Add Vite PWA plugin, manifest, icons, update flow, install prompt.

### **Module 4 — Runtime Caching**

Cache strategies, stale‑while‑revalidate, network‑first, cache‑first, route matching.

### **Module 5 — IndexedDB + Offline Data**

Store API responses offline, sync local changes, queue writes.

### **Module 6 — Background Sync**

Retry failed POSTs, queue mutations, handle offline submissions.

### **Module 7 — Push Notifications**

VAPID keys, subscription endpoints, sending pushes, handling payloads.

### **Module 8 — Production Hardening**

Versioning, cache busting, Lighthouse, deployment, HTTPS, hosting.
